Rules the copy follows
  • Name the consequence before the cause — 9 test cases were dropped, not duplicate row detected.
  • Group by kind, never one per column — 4 empty columns is one line.
  • Problems sort above notices. Never alphabetical, never by column order.
  • Quote the offending value so it can be found in the sheet.
  • Nothing is ever blocked. A load that refuses leaves you with nothing.
